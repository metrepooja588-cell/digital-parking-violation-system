# 🚗 Digital Parking Violation System

A web-based system to report parking violations, generate challans with photo evidence, search and pay fines online.

Built with Python Flask for Software Testing and QA Lab CA3.

## ✨ Features
- Report Parking Violation with Vehicle Number, Location, Photo
- Auto Challan Generation - Rs. 500 Fine
- Search Challan by Vehicle Number
- Pay Fine Online - Pending / Paid Status
- Dashboard with Total Challans, Total Fines, Pending Count
- Violation Types: No Parking, Footpath, Disabled Spot, Double Parking

## 🛠️ Tech Stack
- Language: Python
- Framework: Flask
- Frontend: HTML, CSS
- Testing: Manual Testing, Functional Testing
